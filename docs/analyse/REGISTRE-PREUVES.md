## Échelle de certitude

- **O — Observé** : contenu directement lisible dans une source publique. Préciser « déclaration éditeur » ou « observation publiée » ; ne pas confondre les deux.
- **D — Déduit** : interprétation justifiée avec confiance faible, moyenne ou élevée. Cette confiance est qualitative, pas une probabilité mesurée.
- **I — Inconnu** : manque de preuve ; proposer une vérification concrète.
- **P — Proposition indépendante** : choix pour notre produit, sans attribution à Legora.

Les résultats de moteurs de recherche ont servi à découvrir les sources. Les domaines ressemblant à Legora, les comparatifs commerciaux et les chiffres d'adoption divergents n'ont pas été utilisés pour établir les fonctionnalités.
